# AIYEMOT — צ'אט קולי עם ChatGPT דרך ימות המשיח 📞🤖

מערכת שמחברת שיחת טלפון בימות המשיח ל-ChatGPT (צ'אט אנונימי, ללא מפתח API):
המאזין שואל בקול, השאלה מתומללת, נשלחת ל-ChatGPT, והתשובה מוקראת לו בטלפון —
מנוקדת, ללא טבלאות, עם ראשי תיבות פתוחים.

```
מאזין ──► שלוחת API (type=api) ──► "מה שאלתך?" ──► תת-שלוחה /1 (הקלטה)
   ▲                                                      │ record_end_goto
   │                                                      ▼
   │                                     STT (Google, he-IL) ──► LOGOUT? ──► איפוס סשן
   │                                                      │ שאלה
   │                                                      ▼
   │                                     Playwright → chatgpt.com (רקע, 10–60 שניות)
   │                                                      │
תת-שלוחה /2 ◄── go_to_folder ── placeholder "ברגע סבלנות" ◄┘
(play_and_return: משמיע את 000.tts וחוזר למעלה אוטומטית)
   │
   └──► חזרה לשלוחת API ──► "מה שאלתך?" ──► /1 ──► ... (לולאה עד ניתוק)
```

## הלולאה

1. כניסה לשלוחה — המאזין שומע **"מה שאלתך?"** ומועבר לתת-שלוחה `/1`.
2. ב-`/1` הוא מקליט את שאלתו; בסיום ההקלטה הוא חוזר אוטומטית למעלה
   (`record_end_goto`), ה-webhook מתומלל את ההקלטה ומוחק אותה מיד.
3. אם התמלול הוא **בדיוק** `LOG OUT` / `LOGOUT` / `EXIT` — שיחת ה-ChatGPT
   מאופסת, נשמע "נפתח סשן חדש" והלולאה ממשיכה באותה שיחת טלפון.
4. אחרת: קובץ תשובה עם "ברגע סבלנות" נכתב מיידית בתת-שלוחה `/2`, השאלה
   נשלחת ל-ChatGPT **ברקע** (הגנרציה אורכת 10–60 שניות — יותר מזמן התשובה
   שימות מאפשר ל-webhook), והמאזין מועבר ל-`/2`.
5. `/2` היא `type=play_and_return`: משמיעה את `000.tts` (מוחלף בתשובה
   האמיתית ברגע שהיא מוכנה) וחוזרת למעלה. הלולאה ממשיכה: שאלה חדשה ב-`/1`,
   תשובה ב-`/2` — כל עוד השיחה חיה.
6. חיוג חדש פותח מחזור חדש אך **שומר את הקשר** עם ChatGPT; רק מילת
   הלוג-אאוט פותחת סשן חדש.

## התאמת הקראה (TTS)

לפני **כל** שליחה לשרת מוכנסת הוראה באנגלית קבועה (`tts_prompt.py`):

> "This answer will be read aloud by a text-to-speech service after it is
> generated... If the user's text is in Hebrew, you MUST write the Hebrew
> fully nikud-pointed... You MUST expand all acronyms... You MUST NOT use
> tables, markdown, bullet points..."

כלומר: אם השאלה בעברית — התשובה תחזור מנוקדת, ראשי תיבות ייפתחו למילים
מלאות, ולא יהיו טבלאות או פורמטים ששירות ההקראה של ימות אינו יודע להקריא.
השאלה עצמה נשלחת עטופה במרקרים `[TTS]...[/TTS]` והתשובה נחתכת אחרי
`[/TTS]` — כך ההוראות לא מגיעות להשמעה.

## התקנה בימות המשיח

צרו את המבנה הבא (החליפו `100` במספר השלוחה שתבחרו):

```
ivr2:/100/ext.ini        ← מתוך ext.ini שבריפו
ivr2:/100/1/ext.ini      ← מתוך 1/ext.ini   (לתקן record_end_goto=/100)
ivr2:/100/2/ext.ini      ← מתוך 2/ext.ini
```

- ב-`ext.ini` הראשי: החליפו את `api_link` בכתובת השרת שפרסתם ואת
  `api_add_0=token=...` בטוקן ה-API שלכם (PHONE:PASSWORD).
- ב-`1/ext.ini`: ודאו ש-`record_end_goto` מצביע על שלוחת ה-API שלכם.
- אין צורך בקבצים נוספים; `000.tts` נוצר אוטומטית ע"י השרת.

## פריסה (Render Free)

1. חברו את הריפו ל-Render: **New → Web Service**.
2. Render מזהה `Dockerfile` אוטומטית (או ידנית: build
   `pip install -r requirements.txt && playwright install chromium`,
   start `uvicorn app:app --host 0.0.0.0 --port $PORT`).
3. Health check path: `/health`.
4. משתני סביבה (אופציונליים):

| משתנה | ברירת מחדל | תפקיד |
|---|---|---|
| `YHM_API_BASE` | `https://www.call2all.co.il/ym/api` | כתובת API של ימות |
| `YHM_API_TOKEN` | — | טוקן לבדיקות מקומיות בלבד (בייצור: מ-ext.ini) |
| `CHAT_TARGET_URL` | `https://chatgpt.com/` | אתר הצ'אט |
| `CHAT_REQUEST_TIMEOUT_S` | `30` | פסק זמן ניווט/שליחה |
| `CHAT_RESPONSE_TIMEOUT_S` | `180` | פסק זמן להשלמת תשובה |
| `STT_LANGUAGE` | `he-IL` | שפת התמלול |
| `BROWSER_HEADLESS` | `1` | `0` לדיבוג עם דפדפן נראה |

## הערות ומגבלות

- **מאזין פעיל יחיד**: קובץ התשובה `000.tts` משותף לכל השיחות; המערכת
  מתוכננת לקו אישי. שיחות מקבילות יתחרו על אותו קובץ.
- **תור שאלות**: אם נשאלת שאלה בזמן שהתשובה הקודמת עדיין נוצרת — היא
  נשמרת ב-`QUESTION_{phone}.tts` ונשלחת אוטומטית בסיום העיבוד; שאלה לא
  הולכת לאיבוד, רק מתעכבת.
- **מכסה אנונימית**: ל-chatgpt.com יש הגבלת הודעות לסשן דפדפן; כשנגמרת
  המאזין ישמע הודעת שגיאה עד איפוס השיחה (חיוג מחדש של השרת = סשן חדש).
- **אנטי-בוט**: דפדפן אמיתי (Playwright Chromium עטוף, headless) עובר בדרך
  כלל מ-IP ביתי; מדטה-סנטר של Render עלול להיתקל באתגרים.
- המצב (state) נשמר **בימות עצמה** (`state_{phone}.tts`) — עמיד לריסטרטים
  של השרת, בלי דיסק מקומי ובלי DB.
